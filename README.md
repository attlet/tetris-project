# tetris-project

## 프로젝트 주제

파이게임 모듈을 활용해 간단한 테트리스 게임 제작

## 프로젝트 기간

2020/04/06 ~ 2020/06/23


## 프로젝트 목표


1. 파이게임 모듈 사용 : 파이썬에서 제공하는 게임 제작 모듈.

2. 테트리스에 있는 대부분의 시스템 구현하는 것.

3. 인공지능이나, 온라인 서버를 통해 다른 유저랑 게임할 수 있도록 구현.


## 내 역할

온라인으로 상대와 1대1 대결을 할 수 있도록 구현하는 것

1. 소켓 서버 구현 : server와 network파일은 각각 서버 역할과 그 서버에서 정보를 주고받는 역할.

2. 객체를 전송 : 메시지를 주고받는 게 아닌, 다른 팀원이 만든 player객체를 전송해 상대에게 보이도록 함. player객체에 각자 화면을 그려주는 메소드를 이용해 두 사용자의 테트리스 화면이 다 보이도록 함.

3. 메인파일에 온라인 플레이 함수 추가 : 이를 통해 메인 화면에서 온라인 플레이로 접속하도록 함.

4. 아이피는 외부 프로그램 사용 : 하마치(hamachi)라는 프로그램을 통해 아이피 접속이 원활하도록 함.


## 사용된 Tech

파이썬, pygame, socket 모듈


## 배운 점 

1. 기본적인 파이썬 사용법
   
2. 소켓의 개념과, 파이썬을 통해 구현해보는 방법

3. 팀원이 만든 테트리스 객체를 이용해 결국 1대1 온라인 대결을 할 수 있도록 구현에 성공
   


## 아쉬운 점

 시간이 많지 않아 하마치라는 소프트웨어를 통해야 매칭이 가능했음. 시간이 있었다면 대기방이나 매칭을 구현해보면 좋았을 것 같다.
